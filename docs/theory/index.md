PLP imports the discipline of probabilistic programming into LLM workflows. It does this without pretending that LLM strings have tractable densities.

The theory pages summarize the longer notes in `docs/plp_theoretical_foundations.md`, `docs/inference_zoo.md`, `docs/plp_introduction.md`, and the presentation in `docs/presentation/main.tex`.
